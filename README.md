# Waselni — Local Delivery Platform

منصة توصيل محلية بتطبيق واحد متعدد الأدوار.

## Roles
- customer: كل الحسابات الجديدة تبدأ كعميل.
- driver / restaurant / staff: يتم تعيينها من الـSuper Admin.
- admin: حساب Super Admin الأساسي.

## Rules
الإعدادات المتغيرة مثل أسعار التوصيل، العمولات، البونص، طرق الدفع، الدعم، WhatsApp، العروض والإشعارات تُدار من لوحة الإدارة ولا تُثبت داخل التطبيق.

## Architecture
تطبيق واحد متعدد الأدوار + Admin Dashboard + Backend/Database + Realtime GPS + Push Notifications + COD/Online Payments + Driver Ledger.

## Current stage
تهيئة مشروع Expo/React Native تمهيدًا لبناء الـauth والـroles والـdatabase والواجهات.
